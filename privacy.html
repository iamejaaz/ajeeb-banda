Privacy policy

"Ajeeb Banda uploader" is a private tool used only by the owner of the Ajeeb Banda YouTube channel to upload, schedule and manage videos on that channel.

It uses the YouTube Data API and YouTube Analytics API with the channel owner's own Google account. It does not collect, store or share data about any other person. Access tokens are stored only on the owner's computer.

The owner can revoke access at any time at myaccount.google.com/permissions.
